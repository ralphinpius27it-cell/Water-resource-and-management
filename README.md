# 💧 Water Resource Management

## 📌 Project Overview

This project is a Smart Water Monitoring Dashboard developed using Python and Streamlit.

The system simulates water-flow sensor readings and identifies abnormal water usage using threshold-based detection.

## 🎯 Objective

- Monitor water-flow readings
- Detect possible water leakage
- Identify high water usage
- Visualize water-flow data
- Generate water usage reports

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Matplotlib
- Jupyter Notebook
- GitHub

## ⚙️ How It Works

The application generates simulated water-flow sensor readings.

The readings are classified using predefined thresholds:

- Flow rate greater than 5 L/min → High Usage
- Flow rate below 0.5 L/min → Possible Leakage
- Other readings → Normal

## 📊 Dashboard Features

- Water flow monitoring
- Average flow calculation
- Normal usage count
- High usage detection
- Possible leakage detection
- Water-flow graph
- Status distribution chart
- Sensor readings table
- CSV report download
